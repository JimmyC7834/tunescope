## Architecture

The app is a single HTML file with 4 main sections stacked vertically in a phone-dimension layout (max-width 430px):

1. **Spectrum** (20%) — FFT frequency visualization, canvas-rendered
2. **Tuner** (32.5%) — Arc meter ±100 cents, NSDF autocorrelation pitch detection with stabilization (median filter, octave-jump suppression, hysteresis)
3. **Metronome** (22%) — Web Audio API scheduled clicks, tap tempo, time signatures, beat patterns (STD/SWG/MCH)
4. **Waveform** (flex) — Recording/playback with scrubbing, pinch-to-zoom

Bottom bar: recording manager (swipe to switch slots, tap for share/rename/delete).

Each section has a **swipe-left config panel** (swipe from right edge to open, swipe right to close).

### Audio Graph

```
Mic → MicGain(3x) → AnalyserNode → OutputGain → Destination
                   ↘ RecordingDest (MediaStreamDestination)
Playback: BufferSource → AnalyserNode → OutputGain → Destination
Metronome: Oscillator → MetroGain → Destination (separate path)
Pitch Player: Oscillator → PitchGain → AnalyserNode + Output
```

### State Machine

`idle → live → recording → paused → playback → paused`

### Key Globals

- `S` — all app state (mode, freq, note, cents, buffers, UI state)
- `A4` — mutable reference pitch (392–494 Hz)
- `pxPerPeak` — waveform zoom level
- `wavBitDepth` — WAV export bit depth (16 or 24)
